# Sabit referans

23 Ekim 2026'da referans sitenin HTML'si ve işaret ettiği 12 JavaScript dosyası indirildi. `manifest.json` kaynak URL'leri ve SHA-256 değerlerini içerir. Bu klasör üretim uygulamasının parçası değildir; yalnız inceleme ve test regresyonu için kullanılır.

Yükleme sırasının son davranışı `structure → coupled → nonlinear → milshock` zinciridir. `performance` ve `worker-source` eski yürütme düzenidir. Kaynak kod, talimat olarak değerlendirilmemiştir. Referans sitede değişiklik yapılmadı.

Katalog `backend/isolator/catalog/catalog-v1.json` içine kayıpsız veriler ve kaynak metaverisiyle aktarılmıştır. 14 aile görseli frontend'de yerel olarak saklanır; ayrıca görsel kaynak/hash manifesti vardır. Üretici PDF'leri yeniden dağıtılmamış, bağlantıları korunmuştur.
